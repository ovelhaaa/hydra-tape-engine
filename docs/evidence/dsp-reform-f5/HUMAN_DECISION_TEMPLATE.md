# F5 — Modelo de decisão humana

Preencha após ouvir `artifacts/dsp-reform-f5/listening/` (RAW e MATCHED). O JSON
exportado pelo player é a fonte; este arquivo é o registro legível.

```
Pacote: artifacts/dsp-reform-f5/listening
Manifesto SHA-256: <sha256 do manifest.json>
Renders SHA-256: <sha256 do conjunto>
Data / revisor:
Fones / monitoração:
Nível aproximado:

Cena 01 (BPM 120->100, guitarra limpa)
  RAW:     preferência [X/Y/Z/Equivalentes/Rejeitar]  confiança [baixa/média/alta]
  MATCHED: preferência [...]                            confiança [...]
  Observações (alinhamento, capstan, afinação, cauda):

... repetir para as 11 cenas ...

Controle negativo 11: as três soaram idênticas? [sim/não]
  Se não, descreva a diferença e a cena em que apareceu.

Resumo:
  Candidata preferida no geral:
  Candidata rejeitada:
  Casos em que a Vintage (A) foi preferida:
  Casos em que o Clock-Focused foi preferido:
  Casos em que o Capstan foi preferido:

Riscos percebidos:
  - pitch dive / vibrato indesejado:
  - eco fora da grade:
  - mudança de timbre/cauda:
  - Reverse fora do pulso:

Decisão:
  [ ] Manter F5-A como default e arquivar B/C como experimento
  [ ] Promover F5-B após ajustes (descrever)
  [ ] Promover F5-C após ajustes (descrever)
  [ ] Rejeitar B e C
  [ ] Repetir com mudanças de parâmetros (descrever)

Pendência física reconhecida: [ ] sim  [ ] não
Assinatura:
```

Regras: não inferir aprovação de teste automático; não comparar níveis RAW entre
candidatas como se fossem iguais; MATCHED é para reduzir viés de loudness. A decisão
musical é humana e nenhuma candidata é promovida por este relatório.
